# MC Productions

Website for MC Productions: trailers and upcoming projects by Malcolm and Cole, plus a page for each of us.

- `index.html` - main page (trailers, upcoming projects)
- `malcolm.html` - Malcolm's films and photography
- `cole.html` - Cole's video editing and software
- `content.js` - **all videos, photos and text live here.** Paste a YouTube or Google Drive link into a `url: ""` to add a video.
- `images/` - photo files

Hosted with GitHub Pages.
